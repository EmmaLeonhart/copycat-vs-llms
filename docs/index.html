copycat-vs-llms

A cleanvibe research project reviving a sidelined classic: Hofstadter & Mitchell's Copycat (1980s–90s), a model of fluid analogy-making on a tiny letter-string world. We ask whether a small Copycat-style architecture can solve analogies that today's large language models still get wrong — and map where each one breaks. (Findings below once results land.)

We build a tiny analogy benchmark, run a Copycat-style solver against current LLMs, and map each one's failure boundary.

What this project does

1 · The question

Can a 1980s fluid-analogy model (Copycat) beat modern LLMs on the letter-string analogies they still get wrong — and where does each one break?

2 · Grounded in the literature

Builds on Hofstadter & Mitchell's Copycat (with runnable Python ports) and the live LLM-analogy debate (Webb/Holyoak/Lu emergence vs. Lewis & Mitchell brittleness) — which is fought only on the LLM side. We run the symbolic model as a live competitor. Full survey: literature/REVIEW.md.

3 · The finding

A 1980s symbolic model beat a 2026 12B-parameter LLM: Copycat 11/15 vs. Gemma 3 12B 5/15 — but the failure map is complementary, not a clean sweep. (Preliminary, N=15.)

Findings — preliminary

Both systems are handed the ordered-list relation, so this isolates applying the rule from memorizing a specific alphabet. Copycat 11/15, Gemma 3 12B 5/15. The gap is widest where the literature predicts LLM brittleness — yet the boundary cuts both ways.
